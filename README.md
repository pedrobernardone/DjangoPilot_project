# 🌦️ DjangoPilot — Weather App

Projeto de estudo em **Django** que exibe a temperatura atual de diferentes cidades. Foi criado a partir de um tutorial.

> 🚧 **Status:** em andamento. Por enquanto o repositório contém apenas a camada de apresentação (template HTML e favicon). O código Python do projeto (`manage.py`, configurações, views e rotas) ainda não foi versionado.

## 📦 O que há no repositório

- `templates/index.html`: página que mostra o nome da cidade e a temperatura em °C, com botões para consultar outro local e voltar à página inicial.
- `weatherApp/static/images/`: favicon da aplicação.

## 🛠️ Tecnologias

- Python 3.13
- [Django](https://www.djangoproject.com/) (sistema de templates)
- [Simple.css](https://simplecss.org/) para o estilo da página
